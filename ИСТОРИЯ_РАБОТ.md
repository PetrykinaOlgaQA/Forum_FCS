# Полный перечень работ по проекту «Н Хаб · ВГУ» (Forum_FCS / BD-master)

Документ фиксирует объём доработок ветки **new-version** относительно начального импорта форума: тематическая платформа ФКН ВГУ с постами, товарами, услугами, модерацией и админкой.

---

## 1. База данных и миграции

- **Схема `db/schema.sql`**: пользователи с ролями `user` / `moderator` / `admin`, поле `content_ban_until` для временной блокировки публикаций; темы с `paired_topic_id` для пар «тема–тема»; посты с типами `post` / `good` / `service`, поле `meta` (JSONB) для цены, контактов, тегов; комментарии с `parent_id` (дерево), флаг `deleted_by_moderator`; реакции на посты; таблица **`moderation_log`** для журнала действий персонала; индексы GIN для полнотекстового поиска.
- **SQL-миграции** `db/migrate_v3.sql` … `migrate_v6.sql`: поэтапное обновление существующей БД без полного пересоздания (добавление колонок, таблиц, ограничений — по факту содержимого файлов в репозитории).
- **`create_database.py`**: создание/инициализация БД с учётом актуальной схемы.
- **`rebuild_rich_db.py`**: сценарий полной пересборки наполненной демо-базы (контент, персоны, посты и комментарии); после пересборки старые сессии браузера могут ссылаться на несуществующих пользователей (см. п. 8).

---

## 2. Авторизация и безопасность паролей

- **`auth_passwords.py`**: хеширование и проверка паролей (bcrypt-совместимый подход), отказ от хранения паролей в открытом виде.
- Регистрация и вход обновлены под новую модель; демо-администратор создаётся при старте приложения (`ensure_demo_admin` в `app.py`).

---

## 3. Прикладная логика (`app.py`)

- Маршруты: главная с фильтрами и выдачей постов, темы, создание темы, пост (просмотр + комментарии + лайк), создание/редактирование/удаление поста, редактирование/удаление комментария, пара тем «pairs», профиль, светлая/тёмная тема (`toggle_dark_mode`), выход.
- **API**: `POST /api/login`, `POST /api/post/<id>/like` для сценариев без полной перезагрузки страницы где применимо.
- **Загрузка файлов** для объявлений о товарах: ограничение расширений и размера, каталог `static/uploads/goods/`.
- **Модерация и мат**: интеграция сервиса ненормативной лексики, бан публикаций по времени, журнал модерации при удалениях персоналом с обязательной причиной.
- **Опциональная токсичность (ML)**: загрузка `ml/models/toxicity_model.joblib`, порог из переменной окружения `TOXIC_BLOCK_THRESHOLD`.
- **`@app.before_request` `ensure_session_user_exists`**: если в сессии указан `user_id`, отсутствующий в таблице `users` (например после `rebuild_rich_db.py`), сессия сбрасывается с подсказкой войти снова — устраняет ошибку внешнего ключа при комментариях.

---

## 4. Репозитории

- **`repositories/user_repository.py`**: работа с пользователями, ролями, `content_ban_until`, операции для админки и мутов.
- **`repositories/topic_repository.py`**, **`post_repository.py`**, **`comment_repository.py`**: темы, посты с типами и метаданными, вложенные комментарии, мягкое удаление.
- **`repositories/reaction_repository.py`**: лайки/дизлайки (или единая реакция по схеме).

---

## 5. Сервисы

- **`services/post_fields.py`**: разбор и валидация полей поста (цена в рублях, URL, Telegram и т.п.).
- **`services/profanity.py`**: детекция нецензурной лексики, согласованная с банами и UI.
- **`services/toxicity.py`**: обёртка/логика токсичности (при наличии модели).

---

## 6. Интерфейс (шаблоны)

- **`templates/base.html`**: единая шапка «Н Хаб · ВГУ», навигация, тёмная тема, модальные подсказки по мату.
- **`templates/index.html`**: лента с фильтрами (период, тип поста), оформление карточек.
- **`templates/post.html`**: дерево комментариев, ответы, отправка по Ctrl+Enter, реакции.
- **`templates/login.html`**, **`register.html`**, **`create_post.html`**, **`create_topic.html`**, **`edit_*`**: обновлённый UI и поля под типы постов и загрузки.
- **`templates/_profanity_shame_banner.html`**, ассет **`static/img/profanity-shame.png`**: баннер «стыда» при нарушениях правил лексики.
- Удалены устаревшие шаблоны `*_old.html`.
- **`templates/admin/`**: панель администратора — дашборд, пользователи, посты, муты, темы; действия удаления с указанием причины для журнала.

---

## 7. Данные и зависимости

- **`seed_fcs_vsu.py`**: сиды под сценарии ФКН/ВГУ.
- **`requirements.txt`**: Flask 3, SQLAlchemy 2, драйверы PostgreSQL (`pg8000`, `psycopg2-binary`), Alembic, для ML — `scikit-learn`, `joblib`.

---

## 8. Известные сценарии эксплуатации

- После **`python rebuild_rich_db.py --yes`** пользователи из старой БД исчезают; необходимо **повторно зарегистрироваться или войти**. Приложение дополнительно очищает «битую» сессию при первом же запросе после пересборки.
