# Н Хаб · ВГУ

**Тематическая веб-платформа ФКН ВГУ** — обсуждения, объявления о товарах и услугах, комментарии, лайки и модерация.

</div>

---

## Возможности

| | |
|:---|:---|
| **Посты** | Типы: обсуждение, товар, услуга; метаданные (цена, контакты, фото для товаров) |
| **Лента** | Фильтры, поиск, сортировка, лайки с главной |
| **Комментарии** | Дерево ответов, Ctrl+Enter для отправки |
| **Роли** | Пользователь, модератор, администратор |
| **Модерация** | Журнал действий, удаление с причиной, муты и бан публикаций |
| **Контент-фильтры** | Мат (`services/profanity.py`), опционально ML-токсичность (`ml/models/toxicity_model.joblib`) |
| **Админка** | Пользователи, посты, темы, муты (`/admin`) |

## Установка и запуск

### 1. Клонирование

```powershell
git clone https://github.com/PetrykinaOlgaQA/Forum_FCS.git
cd Forum_FCS
```

### 2. Виртуальное окружение и зависимости

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 3. Переменные окружения

Создайте файл `.env` в корне проекта (можно скопировать из `.env.example`):

| Переменная | Назначение |
|------------|------------|
| `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT`, `DB_NAME` | Подключение к PostgreSQL |
| `FLASK_SECRET_KEY` | Секрет сессий (**обязательно сменить** в проде) |
| `DATABASE_URL` | Полный URL БД (если задан — имеет приоритет над полями выше) |
| `TOXIC_BLOCK_THRESHOLD` | Порог ML-токсичности, по умолчанию `0.72` |

### 4. База данных

```powershell
python create_database.py
```

Создаёт БД (если нет), применяет `db/schema.sql`. При старте `app.py` дополнительно подхватываются `db/migrate_v*.sql` для уже существующих баз.

### 5. (Опционально) Данные

```powershell
python seed_fcs_vsu.py
```

Для насыщенной демо-базы: `python rebuild_rich_db.py --yes` — **пересоздаёт пользователей и контент**; после этого нужно **войти заново**.

### 6. Запуск

```powershell
python app.py
```

Откройте в браузере: **http://127.0.0.1:5000**

## Демо-администратор

При первом старте создаётся пользователь с ролью `admin` (см. константы `DEMO_ADMIN_EMAIL` / пароль в `app.py`). Смените пароль после развёртывания.

## Что сделано

> Краткий перечень работ по ветке **new-version**.

- сделала новую версию платформы вместо старого форума
- обновила схему БД: роли, бан публикаций, пары тем, типы постов (обсуждение / товар / услуга), JSON-метаданные, дерево комментариев, журнал модерации
- добавила миграции SQL `migrate_v3` … `migrate_v6` и скрипт полной пересборки демо-данных `rebuild_rich_db.py`
- сделала хеширование паролей и модуль `auth_passwords.py`
- добавила фильтр мата (`services/profanity.py`): проверка текста, временный бан, модалка и баннер в UI
- добавлена ML-модель токсичности (scikit-learn + joblib): опционально блокирует слишком токсичные тексты, если лежит `ml/models/toxicity_model.joblib`
- сделала посты-товары с фото, ценой, контактами; валидация полей в `services/post_fields.py`
- добавила API лайка поста и входа для удобства на фронте
- сделала админ-панель: пользователи, посты, темы, муты, удаление с причиной в лог
- причина удаления у админа показывается только после нажатия «Удалить» (пост / коммент / тема)
- добавила проверку сессии: если пользователь пропал из БД после пересборки — выход из «битой» сессии без ошибки FK
- обновила шаблоны главной, поста, регистрации/входа, тёмная тема, Ctrl+Enter в комментариях
- обновила `requirements.txt`, сиды `seed_fcs_vsu.py`, `create_database.py`

## Обновление старой базы

Для очень старых установок можно выполнить SQL из `db/migrate_v2.sql` вручную. Актуальные `migrate_v3+` подтягиваются при запуске приложения (best-effort).
