## Датасет токсичности

Скрипт `ml/train_toxicity.py` ожидает CSV файл `toxicity_dataset.csv` со столбцами:

- `text` — текст сообщения
- `label` — 0/1, где 1 = токсично

Пример:

```csv
text,label
Привет, как дела?,0
Ты ужасный человек!,1
```

Примечание: при обучении текст преобразуется в набор "корней" (стемов) слов (упрощённый стемминг),
чтобы модель лучше обобщала разные формы одного и того же слова.
